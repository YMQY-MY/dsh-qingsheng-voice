# 清声 · 大肥鱼语音插件 0.1.0

适配本机 DeepSeek Harness 0.2.1-rc.5 与大肥鱼 dsh-dafeiyu 0.1.18。它是独立的 DSH Bundle，不修改 DSH 安装文件，也不修改大肥鱼原包。

## 使用

1. 先启动清声工作台，确认声音模型已就绪。
2. 安装并在 DSH 的插件管理中启用本 Bundle。插件列表中的名字是 dsh-qingsheng-voice。
3. 对话输入框工具栏出现“语音输入”“停止朗读”“自动朗读”。
4. 点击“语音输入”，允许麦克风，讲话后点击“结束录音”。识别结果进入原来的 DSH 草稿框，确认后发送。录音期间可以取消或按 Escape。
5. 自动朗读只处理当前会话新完成的回答。不会播放历史、思考内容、代码块、工具调用和子智能体。发送新的消息、切换会话、开始录音或点击停止都会中止旧声音。
6. 在本 Bundle 详情中选择工作台音色、试听或启动清声。建议在工作台先保存参考音色，获得更稳定的声线。

## 安装与移除

使用包旁的 install-dsh-plugin.ps1。通过 DshDirectory、StudioRoot 参数指定 DSH 安装目录与清声工作区；未指定时安装器会询问。安装前备份 DSH 的插件清单、锁文件和 profile patch。使用 DSH 自带的包管理器安装本地包，不执行安装脚本，不联网下载模型。

已有 DSH 会话不会被安装器关闭；若没有立即出现控件，等当前任务结束后重启 DSH。移除时在 DSH 插件管理中停用或卸载 dsh-qingsheng-voice，清声模型与原有会话保留。

## 架构

DSH Conversation Slot → DSH 已认证的 Connection RPC → 语音插件 → 清声本机 HTTP 接口 → 声音引擎 / 识别器。

朗读通过宿主侧 Windows 播放器输出，DSH 窗口最小化后仍可继续播放；当前会话由输入框的公开 Slot 告知，不抓取页面文本。插件只订阅新会话事件，不回放存储日志，不取得 DeepSeek 密钥，不复制大肥鱼角色资产。

程序、模型和数据沿用清声工作区。插件偏好与短期播放文件放在 data/dsh-plugin；临时 WAV 播放结束删除。生成历史与录音按清声原有机制保存。DSH 自身的插件配置和安装副本仍由它的现有 profile 目录管理。

## 当前边界

- Windows x64；本次实际适配 DSH 0.2.1-rc.5，不保证其他预发布版本的接口不变。
- 等待最终回答提交后，分段生成 WAV 并播放；尚未直接消费首片 PCM，不等同全双工实时通话。
- 最多朗读 6000 字；代码、链接与 Markdown 表格可能不适合直接听读。
- 麦克风为手动开始和结束，最多约 59 秒。没有常开监听、唤醒词或自动发送。
- 清声未启动或模型未加载时会明确显示状态，不会自动切换为系统声音。插件不会在退出时关闭其他程序共用的清声服务。
- 本插件不会改变大肥鱼的口型、动作或气泡文本；声音来自 DSH 当前对话的回复。
