# 清声 · 大肥鱼语音插件

为 DeepSeek-Harness (DSH) 提供本地 TTS 朗读、语音输入与音色工作室，全部在本机运行。

完整文档见仓库根目录的 README。本包是 DSH Bundle，安装后在插件管理中启用 `dsh-qingsheng-voice`。

## 快速开始

1. 安装清声工作台桌面版，确认模型可加载。
2. 在 DSH 插件管理中安装本包。
3. 重启 DSH —— 插件会自动拉起清声服务，无需单独开工作台。
4. 输入框旁出现语音输入、停止朗读、自动朗读；语音设置中可管理音色。
