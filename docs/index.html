它能做什么

🔊

边生成边朗读

回答还在写的时候就开口，不必等整段合成完。长回答也不会让你干等着。

🎙️

对着机器说话

录音转文字直接进输入框，确认之后才发送。识别在本机完成，音频不出门。

🎭

音色随你捏

内嵌工作台可以录参考音锁定音色，也可以直接用文字描述你想要的声音。

💬

说话有情绪

按语义切换语气，停顿、口癖、尾音都落在台词层，听起来像人在讲而不是机器在念。

怎么装

  1. 下载插件包

    从 Releases 下载最新的 zip。工作台和推理引擎都打包在里面了，不用另装别的东西。

  2. 双击安装

    解压后运行 plugins\安装到DSH.cmd。它会自己找到 DSH 的 profile 并完成挂载，不需要你输入任何路径。

  3. 等模型就位

    首次启动会从 HuggingFace 拉取声音模型，约 2.7 GB，只需要一次。之后完全离线。

  4. 开始说话

    重启 DSH，输入框旁边会出现语音按钮。工作台在后台自动运行，不需要你单独打开。

如果你更习惯命令行，也可以从 npm 安装：npm i dsh-qingsheng-voice

Windows x64，Node.js ≥ 22，DSH ≥ 0.2.1-rc.5
显卡
支持 Vulkan。没有独显也能跑，只是慢一些

为什么是本机

你说的话不出门

语音合成和识别都在你自己的显卡上完成。没有 API 调用，没有额度消耗，断网也能用。

工作台是它的一部分

调音色、录参考音、试听这些界面随插件一起装好，不需要额外再装一个桌面程序。
